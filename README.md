# 🤖 AI Job Application Automation

An automated job application system built with Python and FastAPI. The project is designed to process job descriptions, analyze resume information, generate personalized application emails, and automate the job application workflow.

## 🚀 Project Overview

Applying for multiple jobs manually takes a lot of time. This project aims to automate the repetitive parts of the job application process.

```text
Job Description
       ↓
Job Information Extraction
       ↓
Required Skills Extraction
       ↓
Resume Processing
       ↓
Resume ↔ Job Matching
       ↓
Match Score
       ↓
Personalized Email Generation
       ↓
Email Service
       ↓
Resume Attachment
       ↓
Application Tracking
